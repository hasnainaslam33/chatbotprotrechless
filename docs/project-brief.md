# Project Brief: Pro Trenchless AI Sewer Decision Center

## Public name
Instant Sewer & Drain Answers

## Backend/system name
Pro Trenchless AI Sewer Decision Center

## Recommended subdomain
answers.protrenchless.com

## Core idea
The main Pro Trenchless website should keep ranking and converting commercial local search traffic. The AI sewer center should create earlier engagement by helping people understand symptoms, compare estimates, upload camera videos, and decide whether to schedule a professional inspection.

## Core message
Do not just clear the drain. Find the cause.

## Primary audiences
- Homeowners
- Realtors
- Property managers
- Restaurant owners
- Plumbers
- Home inspectors
- Commercial property owners
- Other users with sewer or drain concerns

## Conversion goals
Move qualified users toward one of these actions:

- Upload a sewer camera video
- Upload an estimate
- Book a sewer camera inspection
- Call Pro Trenchless
- Request a second opinion
- Join as a plumber/referral partner

## Required lead fields
- Name
- Phone
- Email
- Property address
- User type
- Problem type
- Urgency
- Uploaded files
- Preferred appointment time
- Consent to be contacted

## Value-first CTA rule
The tool should not ask for a booking immediately. First, it should provide useful guidance, then offer a soft next step.

Example CTAs:

- Based on what you described, a camera inspection with locate would be the smartest next step.
- This is worth a second opinion before approving a full replacement.
- If you have the video or estimate, Pro Trenchless can review it before you spend thousands.
- Would you like to schedule an inspection or upload your estimate for review?
